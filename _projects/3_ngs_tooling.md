A collection of the smaller things built along the way, mostly to make my own analyses reproducible
and someone else's analyses less painful:

- **VCF/MAF utilities** — parsing and visualization of somatic variant files, built while working
  with Duplex Sequencing and Bulk Segregant Analysis data.
- **Non-canonical DNA structure finder** — a script for identifying sequences capable of forming
  non-B DNA structures.
- **Snakemake pipelines** — reproducible somatic variant analysis workflows that run on HPC
  (UNMC Swan / Holland Computing Center).

Code lives on [GitHub](https://github.com/Tsarin2061).
